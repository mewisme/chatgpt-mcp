# chatgpt-mcp

[![CI](https://github.com/mewisme/chatgpt-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/mewisme/chatgpt-mcp/actions/workflows/ci.yml)
[![Release](https://github.com/mewisme/chatgpt-mcp/actions/workflows/release.yml/badge.svg)](https://github.com/mewisme/chatgpt-mcp/actions/workflows/release.yml)

A self-hosted Model Context Protocol (MCP) server written in Go with an embedded React admin dashboard.

chatgpt-mcp provides a single binary runtime for running MCP tools, managing upstream MCP servers, monitoring activity, and exposing a local administration interface.

## Features

- MCP protocol runtime
- JSON-RPC validation and error handling
- MCP session lifecycle management
- Tool registry and tool execution
- Upstream MCP server management
- Embedded React admin dashboard
- Token based authentication
- Activity stream and audit events
- Managed tunnel process integration
- Cross-platform single binary distribution

## Installation

### Local source install

Requires Go 1.27+, Node.js 24+, and pnpm 11+.

From a cloned repository, run the same command on Linux, Windows, or macOS:

```bash
node scripts/install-local.mjs
```

The installer restores frontend dependencies, builds the admin dashboard, copies `web/dist` into the ignored `internal/web/dist` embed directory, then runs:

```bash
go install .
```

To skip the dependency install when `web/node_modules` is already current:

```bash
node scripts/install-local.mjs --no-deps
```

If `web/dist` was already built or downloaded:

```bash
node scripts/install-local.mjs --from-dist
```

### Binary release

Download the latest release from GitHub Releases.

Supported platforms:

- Linux amd64/arm64
- Windows amd64/arm64
- macOS amd64/arm64

Run:

```bash
chatgpt-mcp
```

## Quick start

Initialize configuration:

```bash
chatgpt-mcp init
```

Start server:

```bash
chatgpt-mcp serve
```

Open the admin dashboard:

```text
http://127.0.0.1:37422
```

Check version:

```bash
chatgpt-mcp --version
```

## Authentication

chatgpt-mcp stores only token hashes. Tokens are printed once when created.

Create MCP token:

```bash
chatgpt-mcp auth mcp-create
```

Create admin token:

```bash
chatgpt-mcp auth admin-create
```

Use tokens with:

```http
Authorization: Bearer <token>
```

## Tunnel

Run a managed tunnel process:

```bash
chatgpt-mcp tunnel configure --command cloudflared --arg tunnel --arg run
chatgpt-mcp tunnel enable
```

Check status:

```bash
chatgpt-mcp tunnel status
```

## Development

Requirements:

- Go 1.27+
- Node.js 24+
- pnpm 11+

Install frontend dependencies:

```bash
pnpm --dir web install
```

Build and prepare the embedded admin dashboard:

```bash
pnpm --dir web build
node scripts/prepare-web-embed.mjs
```

`internal/web/dist` is generated locally and intentionally ignored by Git. Prepare the embed before commands that compile the Go package.

Run backend checks:

```bash
go test ./...
go vet ./...
```

Run frontend checks:

```bash
cd web
pnpm lint
pnpm typecheck
pnpm build
```

## CI

Pull requests and pushes to `main` run:

- Frontend lint, typecheck, and production build
- Native local-install smoke, Go tests, Go vet, and Go build on Linux, Windows, and macOS
- Cross-builds for release target OS/architecture pairs

CI builds the frontend once, passes `web/dist` as an artifact, and reuses it on native and cross-build jobs. The native matrix runs `scripts/install-local.mjs --from-dist`, so the same local install path is continuously validated on all supported operating systems.

## Release

Releases are generated by GoReleaser.

Create a tag:

```bash
git tag v0.0.1
git push origin v0.0.1
```

Release artifacts contain the standalone binary with the admin dashboard embedded.
